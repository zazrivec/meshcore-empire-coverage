## Hungary

- [mc868.hu](https://mc868.hu/) — main Hungarian hub: Telegram group, Facebook group, GitHub, a "live" mesh map plus the official map with settings.
- [meshcore.creativo.hu](https://meshcore.creativo.hu/) — configuration wizard.
- [mesh.creativo.hu](https://mesh.creativo.hu/) — Meshtastic vs. MeshCore comparison.

The Hungarian network also extends into Slovakia and Austria.

**Command for the network's dominant preset** (~52.9% of nodes):

```
set radio 869.618,62.5,7,5
```
