## Luxembourg

- [meshcore.lu](https://www.meshcore.lu/) — main Luxembourg hub.
- [luxmesh.lu](https://luxmesh.lu/) — community portal.
- [wardriving.luxmesh.lu](https://wardriving.luxmesh.lu/) — wardriving/coverage mapping.
- [map.meshcore.io](https://map.meshcore.io/) — official global network map.
- [Discord](https://discord.gg/NFnFeCCMvG) — community Discord server.
- [C3L (social.c3l.lu)](https://www.c3l.lu/) — Luxembourg tech/amateur-radio community active around MeshCore repeaters.
- [LARU — Luxembourg Amateur Radio Union](https://www.laru.lu/) — amateur radio union, organises MeshCore workshops and runs repeaters.
- [lemcit.lu](https://www.lemcit.lu/)
- [beprepared.lu](https://www.beprepared.lu/) — emergency preparedness, relevant for using MeshCore as backup communication.

**Command for the network's dominant preset** (~94.8% of nodes):

```
set radio 869.618,62.5,8,8
```
