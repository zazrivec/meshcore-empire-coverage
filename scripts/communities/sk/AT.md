## Rakúsko

- [meshcore.at](https://meshcore.at/en/) — hlavný komunitný hub: 300+ aktívnych uzlov, mapa (aj per Bundesland, napr. [Oberösterreich](https://meshcore.at/en/bundesland/oberoesterreich)), setup guides, HW odporúčania, stretnutia.
- [meshcore-austria.at](https://meshcore-austria.at/doku.php?id=start) — dokumentačné wiki (DokuWiki).

Repeatery sa taggujú regionálne (napr. `europe`, `at`) pre cielené smerovanie. Odporúčané nastavenia: Zero-Hop Advert ~240 min, Flood-Advert 24–48h.

**Príkaz pre dominantný preset v sieti** (~76.3% uzlov):

```
set radio 869.618,62.5,8,8
```
